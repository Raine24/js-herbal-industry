# JS HERBAL INDUSTRY — E-Commerce Storefront

> **Trust in Nature, Promise of Quality!**  
> *Inspired by Nature, Defined by Quality.*

A modern, high-performance botanical e-commerce storefront for **JS Herbal Industry** (Karachi Chowrangi, Karachi, Pakistan). Built with token-driven responsive design inspired by [Tibico Health](https://www.tibicohealth.com/), featuring zero-dependency vanilla JavaScript animations, accessible interactive drawers, direct WhatsApp order builder, and WCAG 2.2 AA compliant typography.

## 🌿 Core Features

- **Exact Tibico-Inspired Architecture**:
  - Full-width dual announcement marquees and announcement banner.
  - Interactive hero carousel with auto-cycle, swipe detection, and rotating seal badge.
  - 4-column product showcase cards with 7-state interaction model (default, hover, focus, active, loading, error, disabled).
  - 3-column "Why Choose Us" spotlight grid.
  - Split factory & quality commitment story sections with reverse flow.
  - Horizontal looping facility gallery showcasing cleanroom extraction and blending.
  - 8-pillar core values grid.
  - Fully accessible collapsible FAQ accordion.
- **Direct WhatsApp Order Engine**:
  - Interactive WhatsApp Order Builder form (`0342-7940339`) with automatic pre-filled formatting.
  - Slide-out Cart/Inquiry Drawer with quantity selectors and dynamic total calculation.
  - Direct customer support and factory inquiry form.
- **Ultra-Fast & Vercel Ready**:
  - Zero framework overhead — pure semantic HTML5, CSS3 tokens, and modular vanilla JavaScript.
  - Instant deployment to Vercel with zero configuration required.
  - Responsive across all viewports (Mobile 390px, Tablet 768px, Desktop 1440px+).

## 🚀 Deploying to Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** (Static Site).
3. Root Directory: `./`
4. Click **Deploy** — your live storefront will be deployed with global CDN distribution and SSL encryption.
